Background

Videos are a very common e-learning content medium, on platforms such as YouTube, Coursera, and Udemy. But accessibility for videos is not straightforward. Videos present information temporally, vary in styles, and rely on both audio and visual understanding.

Formative study

Our formative study reveals many existing access barriers. We conducted a web survey with 53 participants from various backgrounds (age, education, disability status, and more). Even though video-based learning is widely used, many access barriers persist.

Key findings. Videos are still hard to follow, see, and navigate.

What is SmartLearn?

An accessible video-based e-learning system that uses multiple approaches to support learners with diverse abilities. It uses temporal and visual accessibility solutions, each answering one key finding:

  • Smart ReplayHelps learners follow.
  • Visual HighlightsHelps learners see.
  • LLM ChaptersHelps learners navigate.

SmartLearn system

How the pipeline works:

  1. Video: frame activity detection, OCR, and shot detection.
  2. Audio: speech to text, then semantic segmentation (combined with shot detection) and transcription.
  3. Player: Visual Highlights mark the active part of the slide, LLM Chapters list summarized sections, and Smart Replay sits in the playback controls.

Lessons learned

  • Chapter generation trade-offMore chapters give control, but fewer give a simpler experience. This calls for a balance between detail and simplicity.
  • Replay button underutilizationIts distinction from chapters was confusing, its function was not unique enough, and it lacked transparency about the outcome.
  • Speed change strategiesWords-per-second (WPS) speed changes led to unnatural speech and a confusing pace. But they also, unintentionally, increased attention.

Design guidelines

  • The design should be responsive to both user actions and content.
  • The user experience should be customizable on all dimensions.
  • The design should be transparent and communicate information about the system and content.
